## Workflows

Repeatable group actions — deploy, restart, health-check — without loose scripts outside North.

- Run from the connection panel, the **Connect** split menu, or the Command Palette
- Follow the run in a tab with timeline, per-step log and Retry / Continue / Cancel
- Group variables + run-time inputs; secrets stay on the **connection**, never in the workflow

## Light theme

Light theme drops the mid-gray wash for slate-100: a bright canvas, white panels, and sharper text.

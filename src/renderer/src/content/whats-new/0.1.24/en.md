## Connect

- **Local terminal:** the Command Palette (⌘/Ctrl+K) now has a "Local terminal" item that opens a shell on your own machine, right inside North — no host, no credential, no saved Connection
- **Tabs show the client name:** connection, Access and API tabs now show the client next to the environment badge — before, only workflow-run tabs had this, making it easy to confuse tabs from different clients in the same environment (e.g. "PROD")

See the [Connect](connect) manual chapter.

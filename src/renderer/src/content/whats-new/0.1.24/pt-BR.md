## Conectar

- **Terminal local:** a Command Palette (⌘/Ctrl+K) agora tem um item "Terminal local" que abre o shell da própria máquina, direto no North — sem host, sem credencial, sem Connection cadastrada
- **Abas com o nome do cliente:** abas de conexão, Access e API agora mostram o cliente ao lado do badge de ambiente — antes só as abas de workflow tinham isso, e era fácil confundir abas de clientes diferentes no mesmo ambiente (ex.: "PROD")

Ver o capítulo [Conectar](connect) no manual.

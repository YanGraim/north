## Conectar

- **Terminal local:** la Command Palette (⌘/Ctrl+K) ahora tiene un ítem "Terminal local" que abre el shell de tu propia máquina, directo en North — sin host, sin credencial, sin Connection guardada
- **Pestañas con el nombre del cliente:** las pestañas de conexión, Access y API ahora muestran el cliente junto al badge de entorno — antes solo las pestañas de workflow-run tenían esto, y era fácil confundir pestañas de clientes distintos en el mismo entorno (ej.: "PROD")

Ver el capítulo [Conectar](connect) en el manual.

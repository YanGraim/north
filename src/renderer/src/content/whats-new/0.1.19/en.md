## APIs in the sidebar

Collections live in the **APIs** section — global or per client — without connecting an Access first.

- Import/export Postman v2.1; the environment selector uses API Accesses (`HML — teste`)
- Connect on an API Access still opens the studio with that environment pre-selected
- Search endpoints in Collections and History
- No timeout by default; **Cancel** aborts the request
- Sending overlay with elapsed time; confirm before closing a dirty tab
- Cleaner headers, params, and variables tables

See the [API client](api) chapter in the manual.

## Export SQL results

In the SQL studio, **Export** (⌘/Ctrl+Shift+E) saves CSV, JSON, Excel, PDF, or SQL INSERT — selection, visible grid, or full query (up to 100k rows).

See the [SQL studio](database) chapter in the manual.

## APIs na sidebar

Collections ficam na seção **APIs** — globais ou por cliente — sem conectar um Access antes.

- Importar/exportar Postman v2.1; o seletor de ambiente usa Accesses API (`HML — teste`)
- Conectar num Access API ainda abre o estúdio com aquele ambiente pré-selecionado
- Busca de endpoints em Collections e no Histórico
- Sem timeout por padrão; **Cancelar** aborta a request
- Overlay de envio com tempo decorrido; confirmação ao fechar aba com alterações
- Tabelas de headers, params e variáveis mais limpas

Ver o capítulo [Cliente API](api) no manual.

## Exportar resultados SQL

No estúdio SQL, **Exportar** (⌘/Ctrl+Shift+E) grava CSV, JSON, Excel, PDF ou SQL INSERT — seleção, grade visível ou query completa (até 100 mil linhas).

Ver o capítulo [Estúdio SQL](database) no manual.

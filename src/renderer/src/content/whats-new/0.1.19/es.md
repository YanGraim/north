## APIs en la barra lateral

Las collections viven en la sección **APIs** — globales o por cliente — sin conectar un Access antes.

- Importar/exportar Postman v2.1; el selector de entorno usa Accesses API (`HML — teste`)
- Conectar en un Access API sigue abriendo el estudio con ese entorno preseleccionado
- Búsqueda de endpoints en Collections y en el Historial
- Sin timeout por defecto; **Cancelar** aborta la request
- Overlay de envío con tiempo transcurrido; confirmación al cerrar una pestaña sucia
- Tablas de headers, params y variables más limpias

Ver el capítulo [Cliente API](api) en el manual.

## Exportar resultados SQL

En el estudio SQL, **Exportar** (⌘/Ctrl+Shift+E) guarda CSV, JSON, Excel, PDF o SQL INSERT — selección, grilla visible o query completa (hasta 100 mil filas).

Ver el capítulo [Estudio SQL](database) en el manual.

## Tray and VPN

- **Close to the tray:** closing the window can hide North in the icon; sessions and VPNs keep running until **Sair do North**
- **Icon and alerts:** the tray shows when a VPN is on; North notifies you when a VPN connects, turns off, or drops

See [Getting started](getting-started) and [VPNs](vpns) in the manual.

## Terminal and files

- **Edit remotely:** open a file on the server from the terminal or file pane and upload when you save
- **Clickable path:** jump through segments of the current directory
- **Favorite directories:** on the remote SFTP/FTP pane, save the open folder and return with one click
- **Current folder:** quick actions from the session working directory
- **Middle mouse button:** copy or paste in the terminal; Settings can swap roles with the right button

See [Connect](connect) in the manual.

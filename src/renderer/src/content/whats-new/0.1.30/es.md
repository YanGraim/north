## Workflows

- **Tags Git con sudo:** el dropdown en vivo de tags ahora usa la **Contraseña sudo** de la conexión (cuando está configurada) para repositorios solo accesibles como otro usuario, y ahora aparecen mensajes de error reales (permiso denegado, Git antiguo en el servidor) en vez de un genérico "no se encontraron tags"

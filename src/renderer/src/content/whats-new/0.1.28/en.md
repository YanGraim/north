## Workflows

- **Deploy by tag:** a workflow input can now become a dropdown of **real Git tags**, fetched live from the server (`git fetch --tags`) right before running — no more typing the tag by hand
- **"Deploy by tag (Git)" shortcut:** one click creates the input fully configured (key, type, source and repository path), instead of setting each field by hand
- **Inputs editor:** you can now create/edit the parameters asked before running a workflow directly from the UI

See the [Workflows](workflows) chapter in the manual.

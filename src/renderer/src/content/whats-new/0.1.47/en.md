## SSH terminal, files, and logs

- **Startup directory:** set which folder to open when you connect to an SSH host
- **Current folder in the terminal:** North shows the working directory (when the shell sends OSC 7) and lists files there with quick actions
- **Log follow:** tail log files from the terminal, from a selection, or from paths saved on the connection — in a dock or a dedicated window
- **SFTP aligned with the terminal:** the SFTP file browser can follow the SSH session’s current folder

## Appearance

- **Automatic mode:** light from 08:00 to 17:00 and dark otherwise, including after resume from sleep
- **Colors and fonts:** pick any accent color and save favorites; more monospace fonts and optional ligatures in the terminal

## VPN

- **Installed components:** the VPN detail view shows what is already on this machine (helper, OpenVPN, etc.)
- **IPsec on Windows:** clearer messages when the WSL distro is missing; service install flow improved

## File uploads in APIs

- **form-data with files:** each field can now be **Text** or **File**, like in Postman. Send an `.xlsx` spreadsheet, a PDF or several images alongside your text fields
- **Binary body:** send a whole file as the request body (e.g. an upload to a pre-signed URL)
- **Postman:** imported and exported collections keep file fields and binary bodies

See the [APIs](api) chapter in the manual.

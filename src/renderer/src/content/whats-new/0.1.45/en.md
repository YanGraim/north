## VPN on Windows and Mac

- **VPN component on Windows:** on computers without OpenVPN, the install stopped halfway and the VPN failed with *Could not install North's VPN component*. OpenVPN and North's VPN service now go in together, with a single administrator prompt
- **FortiGate SSL-VPN on Mac:** North fixes the route when the FortiGate uses its own IP as the tunnel's peer, and the timeout error now says whether the login had already been accepted

See the [VPNs](vpns) chapter in the manual.

## Visual identity and local profile

- **Engine marks** — PostgreSQL, MySQL, MariaDB, Redis, MongoDB, SQL Server and SQLite show official icons in lists, details, palette and sidebar (custom icons still win).
- **Client tree** — expandable groups with connections and accesses as leaves; click opens the item in the center panel.
- **Local profile** — display name and optional e-mail in Settings; initials chip in the sidebar footer (this machine only).
- **Titlebar** — North logo beside the app name.

See [Organization](organization) and [Getting started](getting-started).

## SQL grid

- **Edit in any result** — double-click, F2 or Enter opens a cell (free query, JOIN or table). Save writes an `UPDATE` on the `FROM` table (primary key required in the result set).
- **Column selection** — click the header name for the whole column; drag cells for just some values; the icon sorts; ⌘/Ctrl+C copies the selection.
- **Sum** in the footer for selected columns or cells (including `numeric`/`decimal`); click copies the total. Grid type at 13px so values stay readable while editing.
- **Grid lines** with stronger contrast in light and dark themes, including between columns.

See [SQL studio](database).

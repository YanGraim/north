# Primeros pasos

Flujo sugerido para armar el inventario:

1. Crea un **cliente** (sidebar → Nuevo cliente, o desde el formulario de conexión).
2. Añade un **entorno** y, si quieres, un **grupo**.
3. Crea la **primera conexión** (p. ej. SSH) o el **primer acceso** (login o base de datos).

## Consejos

- Cliente, entorno y grupo se pueden crear directo en el formulario de conexión/acceso.
- Usa etiquetas para cruzar ítems entre clientes.
- Favoritos y recientes aceleran el día a día cuando el inventario crece.
- Ajusta **nombre para mostrar** y correo opcional en Ajustes → Perfil (chip en el pie de la barra lateral).

Cuando el inventario está vacío, la pantalla de conexiones también apunta a este tutorial.

## Apariencia

En **Configuración → Apariencia**, elige Oscuro, Claro, Sistema o Automático. Automático deja la interfaz clara de 08:00 a 17:00 en el reloj de este equipo y oscura el resto del día, con la app abierta. Sistema sigue el tema de Windows, macOS o Linux.

## Abrir con el sistema

En **Configuración → Inicio**, activa **Abrir North al iniciar el sistema** para que North se abra solo al iniciar sesión en Windows, macOS o Linux. Viene desactivado. Para desactivarlo, desmárcalo (o usa las aplicaciones de inicio de Windows / Ítems de inicio de sesión de macOS).

# Getting started

Suggested flow to build your inventory:

1. Create a **client** (sidebar → New client, or from the connection form).
2. Add an **environment** and, optionally, a **group**.
3. Create your **first connection** (e.g. SSH) or **first access** (login or database).

## Tips

- Client, environment and group can be created directly in the connection/access form.
- Use tags to cross-cut items across clients.
- Favorites and recents speed up daily work once the inventory grows.
- Set **display name** and optional e-mail in Settings → Profile (chip in the sidebar footer).

When the inventory is empty, the connections screen also points to this tutorial.

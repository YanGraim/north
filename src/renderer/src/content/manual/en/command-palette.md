# Command Palette

Open with **⌘K** (macOS) or **Ctrl+K** (Windows/Linux).

## What you can do

- Search connections, accesses, clients, environments, groups and tags
- Open a session directly from a result
- Quick actions: new connection, dashboard, favorites, history, settings, import/export

## Main shortcuts

| Action | Shortcut |
| --- | --- |
| Command Palette | ⌘/Ctrl+K |
| Toggle sidebar | ⌘/Ctrl+B |
| New connection | ⌘/Ctrl+N |
| Close tab | ⌘/Ctrl+W |

Type to filter; press Enter to open and Esc to close.

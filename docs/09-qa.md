# QA — checklist pós-MVP

Validação manual contra hosts reais + smoke automatizado. Rodar localmente antes de cortar release.

## Smoke automatizado

```bash
npm run lint
npm run typecheck
npm run test
```

`npm run test` (Vitest) cobre, entre outros:

- auth SSH sem senha / falha de decrypt com mensagem amigável
- vault: encryptor que falha no `decrypt` → mensagem estável
- ProtocolManager: host key accept/reject, open que falha se secret rejeita, histórico no close
- store de sessões: aba otimista `connecting` → anexa `port` no sucesso; `error` no fracasso; `closeTab`

Todos devem permanecer verdes após mudanças de UI/settings.

## Sessão SSH in-app (roteiro rápido)

Confirma o fluxo que o usuário vê ao conectar — a digitação acontece **no terminal dentro do North** (xterm.js na aba da sessão), não no Terminal.app.

1. [ ] Editar conexão → senha válida → Salvar
2. [ ] Conectar → aba **“Conectando…”** aparece de imediato (não tela preta vazia)
3. [ ] Se pedir host key → diálogo acima da sessão; aba mostra “Aguardando confirmação do host…”
4. [ ] Confiar no host (se aplicável)
5. [ ] Digitar no terminal da aba (ex.: `whoami`)
6. [ ] Clicar **Workspace** na tab bar para voltar à lista/sidebar
7. [ ] Em erro de vault/senha → aba com estado de erro + toast legível (não sumir em painel mudo)

## Protocolos

### SSH

- [ ] Conectar com senha
- [ ] Conectar com chave privada (e passphrase, se houver)
- [ ] Host key na primeira conexão — aceitar e persistir
- [ ] Host key mismatch — prompt e rejeição segura
- [ ] Resize do terminal (vim / htop reagem ao NAWS)
- [ ] Fechar aba grava entrada no histórico
- [ ] Digitação no xterm in-app (não em cliente externo)
- [ ] Aba Workspace sempre acessível durante a sessão

### SFTP / FTP

- [ ] Listar diretório remoto
- [ ] Upload com progresso
- [ ] Download com progresso
- [ ] mkdir / rename / delete

### Telnet

- [ ] Abrir sessão terminal
- [ ] Digitação e eco do remoto funcionam

### Serial

- [ ] Picker de portas no formulário de conexão
- [ ] Abrir sessão terminal na porta escolhida

### VNC / RDP

- [ ] Conectar e ver desktop
- [ ] Input de mouse/teclado
- [ ] Clipboard (quando aplicável ao driver)
- [ ] Resize da sessão / viewport
- [ ] Prompt TLS / host key quando o servidor exigir

## Produto

- [ ] CRUD de cliente / ambiente / grupo / conexão / tag
- [ ] Command palette (⌘/Ctrl+K) — typo parcial encontra itens
- [ ] Favoritos e Recentes refletem ações
- [ ] Dashboard mostra stats e atalhos
- [ ] Notas Markdown na conexão (preview)
- [ ] Import → wipe local (ou DB limpo) → export round-trip (JSON **schemaVersion 2**, com accesses)
- [ ] JSON exportado **sem** segredos (`credentialRef` ausente, `includeSecrets: false`)
- [ ] Baixar modelo CSV → preencher 1 servidor + 1 banco + 1 login → importar
- [ ] Import CSV com senhas exige confirmação; vault recebe as credenciais
- [ ] Relatório de import CSV mostra erros por linha (`Linha N: …`)
- [ ] Settings (`/settings`) — versão, import/export JSON, import CSV, modelo, verificar atualizações, link do repo
